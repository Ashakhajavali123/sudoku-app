# Sudoku

A Sudoku game built with Python (Flask), HTML, CSS and JavaScript.

## Features
- Easy, Medium and Hard puzzles, each with a single solution
- Check, Hint and Erase buttons
- Timer

## How to run
1. Install Python from python.org
2. Install Flask: `py -m pip install flask`
3. Start the app: `py app.py`
4. Open http://127.0.0.1:5000 in your browser
